    How to Use — Beetlejuice JR Cue Player
    Getting started: click Beetlejuice JR to load all 54 tracks from the web. Or click 📁 Load Folder to load audio from your computer — no internet needed.
    GO (Space bar) always advances to the next cue and plays it. AUTO cues continue automatically after the gap. MAN cues wait for the next GO.
    Per-cue controls: each row has its own volume, speed, pitch, and loop. Speed changes tempo without affecting pitch. Pitch cycles semitone shifts. L toggles loop (green = on).
    Notes: right-click a cue name to add a note (or press N). The note for Up Next shows in the panel on the right so the operator always knows what's coming.
    Local files: use Load Folder to load a whole folder at once. Save Show stores filenames so you can reload with Load Folder next time. Files marked ⚠ are offline — use Locate file or Load Folder to reconnect.
    SFX Bank: keys 0–9 fire sound effects. Each slot has OVR (overlap), RST (restart), and LOOP modes. PANIC (Esc) kills everything instantly.
    URL cues: use + URL to add a cue from a web link. GitHub raw file links work well. Google Drive links are not supported — use a CDN or GitHub raw URL instead.
    Unsaved changes are shown as an amber dot next to Save Show. The page will warn you before closing if you have unsaved changes.
