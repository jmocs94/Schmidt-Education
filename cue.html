    How to Use Theater Cue Player
    What this is: a simple show-control page for students. Add cues, arrange them, press GO to move forward, and use the SFX Bank for one-off effects.
    + File adds one audio file as a cue. + URL adds a cue from a direct web link. Load Folder loads a whole folder of audio and can reconnect saved cues and SFX by filename.
    Save Show saves your cue list, notes, levels, pitch, loop settings, SFX setup, and any web URLs as JSON. Load Show restores it. If local files are missing, the app marks them offline so you can reconnect them.
    GO always advances to the next cue and plays it. AUTO cues continue after the set gap. MAN cues wait for the next GO. Volume, loop, and pitch are all stored per cue.
    Now Playing shows the current cue. Up Next shows the next cue and its note. Right-click a cue name to edit its note, or press N to edit the current cue note. Double-click a cue name to rename it. Click a cue's pitch button to cycle semitone offsets, and press L to toggle loop for the current cue.
    SFX Bank uses keys 0 through 9. Empty slots can take a local file or a URL. OVR overlaps repeated presses. RST restarts from the beginning. LOOP repeats until the same key is pressed again.
    Prev moves back. Stop stops and rewinds the current cue. Panic silences everything, including SFX. Print / Export opens a printer-friendly cue sheet.
    Icons: globe = web file, monitor = local file loaded this session, warning = offline and needs to be located. Google Drive URLs are not supported for web playback in this app because browser security usually blocks them. Use local files, a CDN, or GitHub raw links instead.
    GitHub tip: use the file's raw URL, not the normal GitHub page. In GitHub, open the file and copy the Raw link. Good format: https://raw.githubusercontent.com/OWNER/REPO/BRANCH/path/to/file.mp3. Avoid github.com/.../blob/... links.
    Hosting tip: a CDN or your own website/server is the most reliable choice for web audio. GitHub raw links may work, but always test before rehearsal or performance.
